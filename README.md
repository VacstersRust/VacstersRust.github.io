# DomPogrom — релиз-кандидат 1.2

Статический сайт по демонтажу домов и построек для Истринского округа.

## Состав

- 15 страниц HTML, единый CSS и JS без сборки.
- 9 полученных от заказчика иллюстративных изображений, оптимизированных в WebP. `assets/images/og-cover.jpg` для предпросмотра ссылок.
- Настроены контакты: **+7 (903) 275-37-02**, **dompogrom@mail.ru**, WhatsApp и Telegram по номеру.
- `robots.txt`, `sitemap.xml`, canonical и OpenGraph для `https://dompogrom.ru`.
- Форма заявки работает через **WhatsApp**: заполняет сообщение, посетитель отправляет его самостоятельно. Фото прикрепляются вручную. Функция «Скопировать текст» копирует текст заявки.
- `api/lead.php` — опциональный обработчик отправки с фото на email, **отключён по умолчанию** до настройки сервера/правового оформления/проверки фактической доставки.

## Запуск

Откройте `index.html` либо загрузите содержимое каталога в корень HTTPS-хостинга домена `dompogrom.ru`.
Для локальной разработки подойдет `python -m http.server 8080` в этой папке.

## Не считать выполненным

- Сайт ещё **не опубликован**: не проверены DNS, TLS, хостинг и реальные аккаунты WhatsApp/Telegram.
- Серверная отправка email-заявок **не активирована**; PHP-скрипт проходит `php -l`, но не проходил тест доставки на боевом хостинге.
- Не подтверждены юридические данные оператора персональных данных; `privacy.html` — подготовительный текст, не утверждённая политика.
- Визуалы от заказчика не являются подтверждённым портфолио. Все визуальные демонстрации имеют соответствующие подписи.
- Существуют зависимости от Google Fonts: в РФ загрузка может быть нестабильной, а сведения о стороннем запросе учитываются в будущей политике данных.

**Главная инструкция:** [`docs/07_RELEASE_HANDOFF.md`](docs/07_RELEASE_HANDOFF.md) — распределение всех изображений, этапы публикации, включение PHP-сервера и остающиеся проверки.
