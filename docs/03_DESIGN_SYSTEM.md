# DomPogrom / Design System v1.0

## Принцип

**Industrial Editorial** = кинематографичный крупный план + типографика инженерной компании + архитектурная сетка. Настроение: собранно, уверенно, дорого, без строительного китча, без предупреждающих жёлто-чёрных лент как доминирующего клише.

## Токены

| Роль | Значение | Применение |
|---|---|---|
| Background | `#101113` | Основной фон |
| Surface | `#161719` | Панели и формы |
| Surface 2 | `#1C1D20` | Контентные пластины |
| Silver | `#BEC2C6` | Второстепенная типографика и метки |
| White metal | `#F1F0ED` | Основной текст и заголовки |
| Signal orange | `#FF711F` | CTA, активные состояния, цифры |
| Orange hover | `#FF9359` | Состояние наведения |
| Line | `rgba(215,218,221,.18)` | Разделители |

**Цветовой ритм:** ~75% графитовых поверхностей, ~20% светлого текста/серебра, ~5% яркого оранжевого. Оранжевый крупным массивом — только на финальном CTA.

## Типографика

- Заголовки: Unbounded 700–800, с локальным фолбэком Arial Black; крупные строки, отрицательный трекинг.
- Основной текст: Manrope 400–800 с системным фолбэком.
- Hero: `clamp(52px, 8.5vw, 132px)` на desktop, адаптив на mobile.
- H2: `clamp(32px, 5vw, 72px)`; текстовые лиды `16–21px`, вспомогательные метки `10–11px`.
- Строки короткие; капс только для крупных заявлений и метаданных.

## Сетка и пейсинг

- Базовый максимальный контент: 1440px с боковыми отступами `clamp(22px,4.5vw,84px)`.
- Сервисные карточки: асимметричная 12-колоночная сетка, размеры 6/3/3 и чередование.
- Изображения: композиции 1.15/0.65/0.65, 3 фокусных плана, не равные «три плитки».
- Ритм: большая типографика → короткая смысловая секция → визуал → линейная техническая схема → CTA.
- Границы блоков: тонкая линия вместо теней и округлённых карточек.
- Фотографии: меньше насыщенности, средний/высокий контраст, свет из одного направления, детали пыли, бетона, защитной экипировки; не затемнять до потери фактуры.

## Компоненты

- Header: sticky, логотип-стрелка, шесть основных ссылок, CTA; мобильная полноэкранная панель.
- Hero: кадр на правой части, градиент на левую, крупный слоган и технические метки.
- ServiceCard: номер, архитектурный чертёж, название, стрелка действия.
- MediaCard: фото, короткая подзаголовочная подпись, метка типа кадра.
- StepRow: крупный номер, этап, компактное объяснение и стрелка.
- ImageSlot: рамка и подсказка по нужному материалу — без случайной стоковой подмены.
- FormField, SummaryPanel, Button, FAQ (`details/summary`), FilterButton, Footer.

## Состояния и доступность

- Различимые hover/focus, клавиатурная навигация, `aria-expanded` для меню, `aria-pressed` для фильтров, статусы для форм, один H1 на каждой странице.
- Мобильная композиция до 390 px без горизонтального переполнения (проверено для главной).
- Анимации отключаются при `prefers-reduced-motion`.
- CSS без фреймворков; без обязательной JS-навигации и без тяжёлых зависимостей.

## Фото-раскадровка будущей съёмки

1. **Establishing / до:** широкий план строения, подъезд, соседние объекты, масштаб.
2. **Action / во время:** динамичная техника или ручной демонтаж крупным планом.
3. **Detail:** ковш, зубья, бетон, арматура, крепёж, инструменты, пыль.
4. **Control:** защита сохраняемых объектов, вывоз и погрузка.
5. **After:** площадка с того же ракурса, что и «до».

Место под каждый кадр предусмотрено в дизайн-системе и галерее. Для портфолио нужны фотографии реальных объектов с разрешением на публикацию.
