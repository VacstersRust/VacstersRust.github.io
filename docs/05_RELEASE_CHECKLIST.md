# Что завершено и что осталось для коммерческого запуска

## Реализовано

- 15 HTML-страниц, весь UI без CMS и runtime-сборки.
- Полностью общая система компонентов, токенов и CSS.
- Главная композиция, 6 услуг с FAQ, процесс, галерея, конфигуратор, контакты.
- Мобильный nav, фильтры, интерактивный перечень работ, формирование запроса.
- WebP-ассеты из пользовательского фото, декоративная инженерная векторная графика.
- Заголовки, meta-description, alt, семантика, внутренняя перелинковка.
- Демонстрационная политика данных и отсутствие фиктивных реквизитов.

## Проверено локально

- HTML-ссылки между страницами ведут на существующие файлы.
- 15 страниц содержат по одному H1.
- Отрисована главная 1440px и 390px; на них нет горизонтального переполнения.
- Срабатывают фильтр галереи, изменение перечня для фундамента и мобильное меню.
- JavaScript выполнялся в Chromium в изолированном документе.

## Остаётся до реального релиза

- Утвердить организационные данные, телефон, почту, каналы связи.
- Подключить форму через выбранную инфраструктуру и проверить реальную доставку.
- Подготовить и проверить официальную политику обработки персональных данных.
- Снять фотографии реальных объектов и заполнить галерею кейсами.
- Утвердить перечень услуг, технику, географию выезда и реальную цену по смете.
- Домен, HTTPS, sitemap, canonical, снятие noindex, robots, индексация.
- Кроссбраузерное тестирование устройств, производительность и Lighthouse на продакшен-домене.
- Юридическая экспертиза публикации информации о демонтажных работах и обязательных согласований для конкретных объектов.
